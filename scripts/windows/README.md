# Windows Utility Scripts

These PowerShell scripts are kept for operator convenience and manual testing on Windows machines.

They are intentionally separated from the repository root because they are not part of the normal application runtime or package entrypoints.

Typical use cases include:

- deployment helpers
- quick API and Prisma checks
- demo and smoke-test flows
- environment-specific troubleshooting

Prefer the documented `pnpm` commands in the root `README.md` and `docs/OPERATIONS.md` first, then use these scripts when you specifically need a Windows helper.
